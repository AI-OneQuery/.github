## 🎯 **GOAL**

- 현장의 실제 문제를 발견하고 해결할 수 있는 AI Solution 만들기
- AI Agent 또는 서비스를 직접 기획하고 구현하기
- 단순한 아이디어에 그치지 않고 실제 사용 가능한 수준까지 발전시키기
- 문제 해결을 통해 명확한 Biz. Impact 만들기
- 팀원 간 적극적인 소통과 협업을 통해 완성도 높은 결과물 만들기

- [ ] AI를 활용했을 때 얻을 수 있는 가치 명확하게 정의하기
- [ ] 핵심 기능 및 사용자 시나리오 구체화하기
- [ ] AI Agent / 서비스 프로토타입 구현하기
- [ ] 실제 사용 가능한 수준인지 지속적으로 검증하기
- [ ] 팀원별 역할을 명확하게 분담하기
- [ ] 매일 진행 상황 공유하기
- [ ] 구현 과정과 의사결정 내용 기록하기
- [ ] 발표 및 시연을 고려하여 결과물 정리하기


## 📌 **RULE**

- 매주 정기적으로 팀 회의 진행하기
- 회의 전까지 각자 맡은 작업 진행하기
- 진행 상황과 이슈는 팀원에게 바로 공유하기
- 문제가 발생했을 때 혼자 해결하려고 오래 고민하지 않기
- 의견이 다를 경우 근거를 가지고 자유롭게 의견 나누기
- 서로의 코드를 적극적으로 리뷰하기
- 기능 구현보다 **문제 해결 가치**를 우선하기
- AI를 사용한 결과물에 대해 반드시 직접 검증하기
- 발표에서는 **문제 → 해결 방법 → AI 활용 → 구현 결과 → 기대 효과**가 명확하게 드러나도록 준비하기


## 🚀 **PROJECT PROCESS**

### 1. Problem

> 우리가 해결하려는 문제는 무엇인가?

- 문제 정의
- 문제 발생 원인 분석
- 현재 해결 방법 조사
- 실제 사용자 및 현업의 Pain Point 파악


### 2. Solution

> AI를 활용하여 어떻게 문제를 해결할 것인가?

- AI 활용 방식 정의
- 핵심 기능 선정
- 사용자 시나리오 작성
- AI Agent / 서비스 구조 설계


### 3. Build

> 실제로 동작하는 결과물을 만든다.

- 빠르게 MVP 구현하기
- 핵심 기능 우선 개발
- 지속적인 테스트 및 개선
- 필요에 따라 AI 모델 및 Tool 연동


### 4. Validate

> 우리가 만든 것이 실제로 문제를 해결하는가?

- 기능 테스트
- 사용자 관점에서 검증
- 기존 방식과 비교
- 개선점 도출


### 5. Present

> 우리가 만든 가치를 효과적으로 전달한다.

- 문제 상황
- 기존 방식의 한계
- AI Solution
- 실제 동작 화면
- Biz. Impact
- 확장 가능성
